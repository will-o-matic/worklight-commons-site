# Worklight Commons Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Worklight Commons LLC marketing site (Home, Support, Privacy, 404) in the "Patchwork commons" style and deploy it to GitHub Pages at `https://worklightcommons.com`.

**Architecture:** Static Astro site with zero client JS. One global stylesheet holds design tokens and all component styles; small `.astro` components render the quilt, project patches and contact band; site constants and the project list live in typed `src/data/*.ts` files. Tests are `node:test` files (run natively by Node 24's TypeScript stripping) that assert on the built `dist/` HTML and on the data/color modules.

**Tech Stack:** Astro 7, TypeScript, `@fontsource/bricolage-grotesque`, `sharp` (OG image script + test), Node 24 `node:test`, GitHub Actions (`withastro/action@v6`, `actions/deploy-pages@v5`).

**Spec:** `docs/superpowers/specs/2026-10-08-worklight-commons-site-design.md`

## Global Constraints

- Site URL `https://worklightcommons.com`; contact email `info@worklightcommons.com`; legal name `Worklight Commons LLC`.
- Repo `will-o-matic/worklight-commons-site`, public, `main` only.
- No JavaScript shipped to the browser (built HTML contains no `<script`).
- No third-party requests from pages: fonts self-hosted via `@fontsource/bricolage-grotesque`; never reference `fonts.googleapis.com`.
- Contact is email only — no forms, no form services.
- Privacy page covers this website only.
- Text on colored patches meets WCAG AA (≥ 4.5:1).
- Responsive down to 360px wide with no horizontal scroll; visible focus styles; respects `prefers-reduced-motion`.
- `trailingSlash: 'always'`: every internal link ends in `/` (or `/#anchor`), matching GitHub Pages' directory URLs so no link triggers a redirect.
- Lighthouse accessibility ≥ 95 on Home, Support, Privacy.
- Nothing is pushed to GitHub until Will approves the locally built site.
- Commits end with:
  ```
  Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>
  Claude-Session: https://claude.ai/code/session_01JD5fHTgaZgQXBjDbY7cz1r
  ```

## Review Focus

1. **Phone at 360px with the long email address** — the `info@worklightcommons.com` pill and footer email must wrap, never cause horizontal scroll. (CSS test in Task 2; measured in browser in Task 6.)
2. **Keyboard user tabbing through colored patches and the dark contact band** — the focus ring must stay visible on sage/slate/terracotta and on ink backgrounds. (CSS test in Task 2; checked in browser in Task 6.)
3. **Every internal link resolves on GitHub Pages without a redirect or 404** — e.g. `/support/`, `/privacy/`, `/#projects`. (Link-resolution test over all built pages in Task 3.)
4. **Sharing the URL in Messages/Slack/App Store review tools** — `og:image` and canonical must be absolute `https://worklightcommons.com/...` URLs and the image must exist at 1200×630. (Tests in Tasks 1 and 4.)
5. **Clicking "Email" on the Support page** — the mailto must open with a correctly URL-encoded subject (`Support%20request`), not a broken address. (Test in Task 3.)

```ts
import { existsSync, readFileSync } from 'node:fs';
import { join } from 'node:path';

export const DIST = join(import.meta.dirname, '..', 'dist');

export function readDist(rel: string): string {
  return readFileSync(join(DIST, rel), 'utf8');
}

export function distExists(rel: string): boolean {
  return existsSync(join(DIST, rel));
}

/** '/' → index.html, '404' → 404.html, '/support/' → support/index.html */
export function page(route: string): string {
  if (route === '/') return readDist('index.html');
  if (route === '404') return readDist('404.html');
  return readDist(join(route.replace(/^\/|\/$/g, ''), 'index.html'));
}
```

```ts
export type Tone = 'sage' | 'mustard' | 'terracotta' | 'slate';

export interface ToneColors {
  bg: string;
  fg: string;
}

/** Patch backgrounds, darkened where needed so text meets WCAG AA. */
export const TONES: Record<Tone, ToneColors> = {
  sage: { bg: '#4e7356', fg: '#fbf7ef' },
  mustard: { bg: '#e3a83b', fg: '#23302a' },
  terracotta: { bg: '#a94a2a', fg: '#fbf7ef' },
  slate: { bg: '#4f6d7a', fg: '#fbf7ef' },
};

function luminance(hex: string): number {
  const channels = [1, 3, 5].map((i) => parseInt(hex.slice(i, i + 2), 16) / 255);
  const [r, g, b] = channels.map((c) => (c <= 0.03928 ? c / 12.92 : ((c + 0.055) / 1.055) ** 2.4));
  return 0.2126 * r + 0.7152 * g + 0.0722 * b;
}

/** WCAG contrast ratio between two #rrggbb colors (1–21). */
export function contrastRatio(a: string, b: string): number {
  const [hi, lo] = [luminance(a), luminance(b)].sort((x, y) => y - x);
  return (hi + 0.05) / (lo + 0.05);
}
```
